# Fast Portuguese Vocabulary

Interactive vocabulary flashcards for **Fast Portuguese**, created by **Ellen Nagasawa**.

The activities include vocabulary from Units 1–15 and allow students to:

- review Portuguese ↔ English vocabulary;
- practice by unit and category;
- track cards they know or want to review again;
- listen to Portuguese words and expressions using browser speech synthesis.

## Pronunciation

The 🔊 pronunciation feature uses the browser's `SpeechSynthesisUtterance` technology.

Pronunciation may vary depending on the browser, device, and available voice. The audio is intended as a practice aid and does not represent all varieties of Portuguese.

## Privacy

The application does not require user accounts.

Self-check progress is stored locally in the user's browser with `localStorage`.

The speech synthesis feature is invoked through the browser's built-in Web Speech functionality. The project itself does not store recordings or pronunciation data.
